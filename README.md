# uhvdb-manuscript
Code used for analyses and figure generation for UHVDB manuscript (https://doi.org/10.64898/2026.05.01.722327).

Code to generate figures is stored as Jupyter notebooks in the indicated directories.

Additional exploratory analyses not included in the manuscript, but related to the manuscript are also included.

WARNING: Code and micromamba environments may not be perfectly reproducible but is included here for the sake of transparency.
